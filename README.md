# Зертханалық жұмыс № 13
**Пән:** Алгоритмдеу және бағдарламалау негіздері  
**Нұсқа:** 3-нұсқа (Банк балансы)

## 1. Тапсырма шарты
Шығыс сомасын шоттағы қалдықпен салыстыру; артық шығыс пен теріс соманы өңдеу.

## 2. Қатені талдау
* **Қате түрі:** Логикалық қателер (шарттардың болмауы) және `ValueError` / `TypeError` ерекшеліктерінің өңделмеуі.
* **Қатенің себебі:** Бастапқы бағдарламада шығыс сомасының шоттағы баланстан асып кетуі (`1000 < 1500`) және теріс сандардың (`-1`) енгізілуі тексерілмеген. Соның салдарынан баланс теріс мәнге (`-500`) өтіп кетеді немесе теріс шығыс азайтылғанда баланс керісінше өсіп кетеді (`500 - (-1) = 501`).
* **Күтілетін нәтиже:** Жарамсыз деректер енгізілгенде бағдарлама `ValueError` немесе `TypeError` ерекшеліктерін ұстап, қолданушыға түсінікті қате хабарламасын шығаруы тиіс.

## 3. Жөндеу қадамдары (Debugging Trace)
`(10000, 2500)` кіріс деректері үшін 2 тоқтату нүктесі (breakpoint) орнатылып, айнымалылар мәні бақыланды:
1. **1-қадам (Кіріс мәндері):** `balance = 10000`, `expense = 2500`
2. **2-қадам (Шарттарды тексеру):** `expense < 0` (`False`), `expense > balance` (`False`) — тексеру сәтті өтті.
3. **3-қадам (Есептеу):** `new_balance = 7500` мәні есептеліп, қайтарылды.

*(Ескерту: Жөндеу барысының скриншоты `debug_screenshot.png` файлында тіркелген).*

## 4. Тестілеу нәтижелері

| № | Тест түрі | Кіріс деректері `(balance, expense)` | Күтілетін және алынған нәтиже | Статус |
|---|---|---|---|---|
| 1 | Қалыпты жағдай | `(10000, 2500)` | `7500` | Сәтті |
| 2 | Шекаралық жағдай (қосымша) | `(1000, 1000)` | `0` | Сәтті |
| 3 | Қате жағдай (артық шығыс) | `(1000, 1500)` | `Қате: Шоттағы қаражат жеткіліксіз (артық шығыс).` | Сәтті |
| 4 | Ерекше жағдай (теріс сома) | `(500, -1)` | `Қате: Сома теріс сан болмауы тиіс.` | Сәтті |
